# Sim-Wallet
SIM Wallet — A secure, mobile-first Bitcoin wallet designed for simple BTC storage, sending, receiving, balance management, and transaction tracking with SIM/mobile-based authentication and strong key protection.

Bitcoin wallet foundation for SIM Guides.

## Network

Development uses Bitcoin Testnet first.

## Core features

- Bitcoin wallet creation
- Available BTC balance
- Pending balance
- Receive Bitcoin
- Send Bitcoin
- QR code
- Transaction history
- SIM/mobile authentication
- PIN and biometric security
- Secure key management

## Security

The SIM/mobile number is an authentication identity only.

It is never used as the Bitcoin private key.

Private keys and recovery phrases must never be sent to the backend or committed to GitHub.
